# Consentimiento de colorimetria: demo (MUESTRA)

Muestra con datos simulados de un consentimiento de colorimetria capilar para firmar en el telefono.

- No es un contrato valido ni asesoria legal; requiere revision legal antes de cualquier uso real.
- Funciona en un solo telefono. No hay servidor: nada de lo que se captura se guarda ni se envia.
- No uses datos reales de salud ni de clientes.
